# Embeddings

## Purpose
Embeddings are used to convert text-based information into numerical
representations so that the agent can search, compare, and retrieve relevant
information efficiently.

In this system, embeddings help the agent remember and recall past information
in a meaningful way.

---

## What is Embedded
The following information is converted into embeddings:
- User preferences and risk profile
- Portfolio holdings and watchlist notes
- Past recommendations and decision rationales
- Key qualitative and fundamental summaries

---

## How Embeddings Are Used
- To retrieve similar past decisions when analyzing new requests
- To match user queries with relevant portfolio or watchlist data
- To maintain context across multiple interactions
- To support explainable and consistent recommendations

---

## Benefits of Using Embeddings
- Enables semantic (meaning-based) search instead of keyword matching
- Improves continuity across conversations
- Reduces repetitive analysis
- Supports scalable memory retrieval

---

## Design Note
This project documents the use of embeddings at a design level only.
No embedding model training or deployment is included as part of this
mini project.
